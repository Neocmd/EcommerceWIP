# Agent Contract Standard

Each agent spec must include:

1. Mission
2. Inputs
3. Outputs
4. In scope
5. Out of scope
6. Definition of Done
7. Required checks
8. Escalation conditions
9. Handoff format

## Handoff Format

Use this fixed payload in PR comments or artifacts:

- Agent:
- Change summary:
- Risks:
- Required follow-up:
- Blocking issues:
- Evidence:
